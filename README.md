# NilOjeda World

Concepto de web para Nil Ojeda: un planeta 3D interactivo donde cada proyecto (MilfShakes, Batido, Room Service, Nil Ojeda, Nil OGT, Nil XYZ) es un continente.

- Un solo `index.html` (Three.js por CDN), imágenes en `img/`.
- Contenido editable en el array `WORLD` dentro de `index.html`.

Concepto creado por [Adelardo López](https://www.linkedin.com/in/adelardo-lopez-sirvent/).
